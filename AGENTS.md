# Winamp MP3 CLI - A CLI application, to play local drive MP3 music

 ✨ WINAMP MP3 CLI - A CLI MP3 Music Player✨

A Rust powered CLI application, that lists and plays your MP3, audio files

 ## Documentation

Document every change / feature that you create / refactor, into a file & save it as a markdown under `docs`
folder.

## Versioning

- Update the version number, in `src/main.rs` file `VERSION` constant
- Update the version number, `version` field in `Cargo.toml`
- Also update the `version` badge in `README.md`
- Use Semantic versioning, Eg: 1.3.1 gets updated as 1.3.2 ..etc.,
- Update the file `CHANGELOG.md` (create it, if not exists) with the version number, date stamp, one liner
points to the overall change.
